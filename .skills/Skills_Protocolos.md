# Matriz de Skills e Protocolos Técnicos

## 1. Protocolo Clean Code (PT-BR)
* **Nomenclatura:** Funções e variáveis em Inglês (ex: `updateAtaStatus`).
* **Comentários:** Descrição detalhada da lógica em Português Brasileiro (PT-BR).
* **Padrão:** Comentários JSDoc em todos os serviços exportados.

## 2. Skills Técnicas Exigidas
| Tecnologia | Aplicação |
| :--- | :--- |
| **React 19** | Hooks nativos e melhoria de performance. |
| **Tailwind v4** | Estilização via @theme e CSS moderno. |
| **Gemini 1.5 Flash** | Síntese de texto e extração de tópicos. |
| **Vitest** | Testes unitários rápidos e integrados ao Vite. |

## 3. Fluxo de Moderação
1.  **Entrada:** Usuário posta comentário.
2.  **Pré-análise:** IA verifica palavras ofensivas ou fora de tema.
3.  **Estado:** Comentário entra como `pendente`.
4.  **Ação:** Moderador aprova/rejeita via dashboard.
5.  **Visibilidade:** Comentário torna-se visível na linha do tempo linear.
