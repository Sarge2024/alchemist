# Definição de Agentes e Personas

## 1. Arquiteto de Sistemas
* **Missão:** Garantir a escalabilidade e a integridade da estrutura DDD.
* **Skills:** C4 Model, ADRs, Estrutura de Bounded Contexts.
* **Responsabilidade:** Definir contratos de interfaces e segurança do Firebase.

## 2. Especialista em Backend
* **Missão:** Implementar a lógica de negócios e integrações de IA.
* **Skills:** Node.js, Express, Firebase Cloud Functions, Prompt Engineering (Gemini).
* **Responsabilidade:** Criar o gerador de Atas e o serviço de moderação.

## 3. Especialista em Frontend
* **Missão:** Criar interfaces de alta performance e experiência fluida.
* **Skills:** React 19, Tailwind v4, Framer Motion.
* **Responsabilidade:** Mural de Atas, Dashboard de Moderação e UI do Acervo.

## 4. Especialista em TDD (Qualidade)
* **Missão:** Manter a estabilidade do sistema durante o refactoring.
* **Skills:** Vitest, Cypress, Testing Library.
* **Responsabilidade:** Cobertura de testes em regras de moderação e votos.

## 5. Gestor de Projeto
* **Missão:** Coordenar o fluxo e garantir a entrega das fases.
* **Skills:** Gestão de Backlog, KPIs de Comunidade.
* **Responsabilidade:** Definir as métricas de sucesso do Resumo Diário.
